# FanFic to Audio 1.2.0

A native Mac app for downloading fanfiction as EPUB and converting it into audiobooks.

**Story downloading is powered by [FanFicFare](https://github.com/JimmXinu/FanFicFare), by Jim Miller (JimmXinu) and the FanFicFare contributors.** Their engine supplies story downloads, site adapters, metadata, EPUB creation and updates, and link extraction. FanFic to Audio is an independent application, not an official FanFicFare release. See the [upstream documentation](https://github.com/JimmXinu/FanFicFare/wiki) and [license](https://github.com/JimmXinu/FanFicFare/blob/main/LICENSE).

## New in this release

- Bulk audiobook queues with move-up/move-down controls and a preview that follows the selected or active book.
- Combine separate EPUBs into an ordered series before narration, preserving original files and resources.
- OpenAI and ElevenLabs speech APIs, with explicit macOS Keychain storage for your own keys.
- Bounded EPUB caching, improved chunk traversal, and fewer intermediate MP3 operations.

## Download and install

Download **FanFic-to-Audio-macOS-AppleSilicon.zip** and the matching **.sha256** file below. Extract it and copy **FanFic to Audio.app** to Applications.

Requires **Apple silicon**, **macOS 14 or later**, and a separate **FFmpeg installation with libmp3lame** for all MP3 exports. Python and FanFicFare are included. This build is **ad hoc signed, not notarized**; macOS may require an app-specific exception before opening it.

Read the [installation guide](https://github.com/thatosxguy/FanFictoAudio/blob/main/docs/installation.md) and [user guide](https://github.com/thatosxguy/FanFictoAudio/blob/main/docs/usage.md). GitHub's automatic Source code archives contain source, not the ready-to-run app.

## Validation and limits

35 native tests and 36 Python tests passed, with synthetic EPUBs and mocked provider responses. Local packaged download/narration and native queue/series workflows were checked. The release bundle passes signature verification. No live paid speech call or authenticated site compatibility was verified; an Intel bundle is not included.

AI previews and exports send selected text to the chosen provider and may incur its API charges. Queues last for the app session, and retry begins the audiobook again. Only unprotected text EPUBs are supported; M4B and embedded MP3 chapter markers are not implemented.

See [Validation](https://github.com/thatosxguy/FanFictoAudio/blob/main/VALIDATION.md) and [Privacy](https://github.com/thatosxguy/FanFictoAudio/blob/main/PRIVACY.md) for details.
