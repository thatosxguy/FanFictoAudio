# Version 1.3.0 — resumable audiobooks and M4B

## Changes

Saved queue order and per-book presets survive app restarts. Compatible completed passages are reused after failure/cancellation instead of being narrated again. Add M4B chapter navigation and EPUB cover art, AI usage estimates and stopping budgets, drag reordering, safe multilingual previews, reliable cancellation, and corrected 192 kbps local MP3 output. Chapter counts and speech API connections are cached/reused.

## Requirements

Apple silicon, macOS 14 or later, and separately installed FFmpeg with libmp3lame and AAC. Python and [FanFicFare](https://github.com/JimmXinu/FanFicFare) are bundled. FanFicFare, by Jim Miller (JimmXinu) and its contributors, powers story downloading, metadata, site adapters, and EPUB writing/updating. Provider keys stay in macOS Keychain.

## Validation and distribution status

49 native and 36 Python tests passed. Integration tests check resume, budgets, all MP3 bitrates, and M4B chapters/cover using synthetic content and mocked providers. The packaged local speech pipeline and native queue restoration checks also passed. See [Validation](../../VALIDATION.md).

This build is **ad hoc signed and not notarized**. Developer ID signing and notarization scripts are included for a later distribution build. A YubiKey signing test succeeded; full-bundle Developer ID signing and Apple notarization have not been verified. Do not describe an asset as notarized unless Apple accepted it and its ticket was stapled and validated. Local evidence, user settings, keys, books, audio, and certificate files are excluded from source publication.

## Recovery and estimates

Resume checkpoints contain generated story audio under the local Application Support directory. Content/settings changes invalidate reuse. The unfinished passage can still be sent and charged again. Cost limits use user-entered estimates; actual provider invoices may differ. Character budgets limit text submitted by the app. Failed/cancelled attempts count conservatively, and cached passages do not count again. See the [User guide](../usage.md).
